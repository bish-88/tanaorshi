# 定期棚卸 ロス確認

定期棚卸の「棚卸ロス分析レポート」（.xls / .xlsx）を読み込んで、**店舗ごとのロス金額**を確認するページです。

👉 **使うページ：https://bish-88.github.io/tanaorshi/**

## 使いかた

1. 上のページを開く
2. 棚卸ロス分析レポートのExcelファイルをドラッグ（またはクリックして選ぶ）
3. 店舗一覧が出ます。店舗の行をクリックすると、推移グラフと部門別の内訳が出ます

Excelファイルはブラウザの中だけで処理されます。サーバーやGitHubには送信・保存されません。

## 表示される内容

| 画面 | 内容 |
|---|---|
| 上の数字 | 全店の売価還元ロス合計・総平均ロス合計、一番ロスが大きい店舗 |
| 店舗一覧 | 店舗ごとの今回ロス・ロス率・前回比・過去平均・1日あたりロス（列名クリックで並べ替え） |
| 店舗の詳細 | 過去8回の推移グラフ、ロス／益が大きい部門TOP5、部門別の全回推移 |
| 部門 × 店舗 | どの店のどの部門でロスが出ているかの一覧（色付き） |
| CSVで保存 | 店舗一覧をExcelで開けるCSVで保存 |

- **売価還元法（売価）**＝レポートの「BK 売価還元合計」
- **総平均法（原価）**＝レポートの「SH 総平均合計」（ファストフーズ・店内厨房）
- プラス＝ロス（在庫が帳簿より少ない）、マイナス＝益
- 売価還元合計が0の回は「実施なし」として扱います
