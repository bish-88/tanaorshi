# 定期棚卸 ロス確認

定期棚卸の「棚卸ロス分析レポート」（.xls / .xlsx）を読み込んで、**店舗ごとのロス金額**を確認するページです。

👉 **使うページ：https://bish-88.github.io/tanaorshi/**

## 使いかた

1. 上のページを開く
2. パスワードを入れて「開く」（「このブラウザで覚える」にチェックすると次から入力不要）
3. 「店舗一覧」「分析」「店舗別」「部門 × 店舗」のタブで見る

棚卸データは暗号化して `data/data.enc` に入っています。パスワードを知らない人には中身は見えません。

## 新しいレポートが出たとき

新しいExcelを Claude に渡すと、`data/data.enc` を作り直して更新します（前のレポートも残して、ページで切りかえられます）。

## 表示される内容

| 画面 | 内容 |
|---|---|
| 上の数字 | 全店の売価還元ロス合計・総平均ロス合計、一番ロスが大きい店舗 |
| 店舗一覧 | 全店舗の今回ロス・ロス率・前回比・過去平均・1日あたりロス（列名クリックで並べ替え） |
| 店舗別 | 店舗をえらぶ（◀▶で前後の店）と、その店の順位・過去8回の推移グラフ、ロス／益が大きい部門TOP5、部門別の全回推移 |
| 部門 × 店舗 | どの店のどの部門でロスが出ているかの一覧（色付き） |
| 季節 | 季節（月）によってロスが増える部門。部門×月のヒートマップと、偶然かどうかの検定 |
| 分析 | 要点まとめ（自動作成）、店舗スコアカード（優先度）、部門パレート、店舗ポジション図、要注意リスト（急増・慢性ロス・慢性益・不明部門）。計算のルールは ANALYSIS.md |
| CSVで保存 | 店舗一覧をExcelで開けるCSVで保存 |

- **売価還元法（売価）**＝レポートの「BK 売価還元合計」
- **総平均法（原価）**＝レポートの「SH 総平均合計」（ファストフーズ・店内厨房）
- プラス＝ロス（在庫が帳簿より少ない）、マイナス＝益
- 店舗合計が0でも部門ごとに数字がある回は「実施した回」です（部門のプラスとマイナスで合計0）。部門の数字もすべて0の回だけ「実施なし」
- ロス率はExcelと同じ表示です
