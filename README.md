# 定期棚卸 ロス確認

定期棚卸の「棚卸ロス分析レポート」（.xls / .xlsx）を読み込んで、**店舗ごとのロス金額**を確認するページです。

👉 **使うページ：https://bish-88.github.io/tanaorshi/**

## 使いかた

1. 上のページを開く
2. パスワードを入れて「開く」（「このブラウザで覚える」にチェックすると次から入力不要）
3. 「店舗一覧」「分析」「店舗別」「部門 × 店舗」のタブで見る

棚卸データは暗号化して `data/data.enc` に入っています。パスワードを知らない人には中身は見えません。

## 新しいレポートが出たとき

新しいExcelを Claude に渡すと、`data/data.enc` を作り直して更新します（前のレポートも残して、ページで切りかえられます）。

## 画面

| タブ | 内容 |
|---|---|
| ダッシュボード | 年・月フィルター（データにある年月だけ）、KPI 6つ、A 月別ロス推移、B 店舗別ロスランキング、C 改善・悪化ランキング、D ロス率比較、前月・前年同月比較、棚卸実施一覧、検索・並び替え・改善/悪化フィルター・CSV出力。すべてフィルターに連動 |
| 店舗詳細 | 店舗名・コード・最新棚卸日、今回/前回の売価還元ロス、増減、ロス率、前回ロス率、棚卸履歴（新しい順）、推移グラフ、部門別 |
| ロス要因分析 | 要点まとめ、優先度スコアカード、部門パレート、店舗ポジション、要注意リスト |
| 季節分析 | 季節によってロスが変わる部門（検定つき） |

| 集計条件・計算式 | すべての計算方法とデータの注意点 |

## データの持ち方（棚卸実施履歴）

- 1件 ＝ 店舗 × 棚卸実施日。レポートの日付（月日）＋レポート作成日からさかのぼった年。
- 複数のレポートは、同じ店舗・同じ実施日を1件にまとめて統合（新しいレポートを優先）。
- 年月フィルターは「その月に棚卸を実施した店舗の回」だけを集計。実施していない店舗・月は集計に入れず「データなし」と表示（0円扱いしない）。
- 前回比較は「同じ店舗の直前の売価還元棚卸」との比較。
- ロス率はレポートの最新回だけに記載があるため、それ以外は「データなし」。平均は単純平均（分母データがないため加重平均は計算しない）。

## パスワード保護の安全性について

- これは「画面でパスワードを判定するだけ」の仕組みではなく、**データ自体を暗号化**しています（AES-GCM 256bit、鍵は PBKDF2-SHA256 60万回でパスワードから作成）。パスワードがないとデータは復号できません。
- ただし **ログイン認証ではありません**。暗号化ファイル（data/data.enc）は公開リポジトリなので誰でもダウンロードでき、**パスワードの総当たりを手元で試すことはできます**。安全性はパスワードの強さで決まります（短い・推測しやすいパスワードは危険）。
- Git の履歴には、以前のパスワードで暗号化した古い data.enc も残っています。
- 利用者ごとのアクセス管理やログが必要な場合は、サーバー側の認証（例：Cloudflare Access、社内サーバー）が必要です。
