定期棚卸 ロス確認

定期棚卸の結果を、店舗ごとのロス金額で確認できます。

パスワードを入れてください

共有されている棚卸データがあります。パスワードを入れると見られます。

店舗別ロス（最新の棚卸）

行をクリックすると「店舗別」でその店舗をくわしく表示します。プラス＝ロス（帳簿より在庫が少ない）、マイナス＝益（在庫が多い）。

部門 × 店舗（売価還元法・最新実施分のロス）

色が濃いほど金額が大きい（赤＝ロス、青＝益）。今回売価還元の棚卸がない店舗は、直近に実施した回の数字です。

新しいレポートをみんなに共有する（更新する人用）

  1. 新しいExcelを上の枠に読み込む
  2. 下のボタンで data.enc を作って保存する（いま表示できるレポートが全部入ります）
  3. GitHub の bish-88/tanaorshi → data フォルダ → Add file → Upload files で data.enc をアップロードして Commit changes
  4. 1〜2分で、みんなのページに新しいデータが出ます

パスワードを変えたいときは、ここに新しいパスワードを入れて作り直してください。

見かた

  • 売価還元法（売価）：部門ごとの「推定在庫高売価 − 実地棚卸在庫高売価」。レポートの BK 売価還元合計 の数字です。
  • 総平均法（原価）：ファストフーズ・店内厨房の「（推定在庫数 − 実地棚卸在庫数）× 前月平均単価」。レポートの SH 総平均合計 の数字です。
  • 売価と原価で基準がちがうため、2つは足さずに別々に表示しています。
  • プラス＝ロス（帳簿より在庫が少ない）、マイナス＝益（帳簿より在庫が多い）。
  • ロス率はレポートに入っている最新回の数字です（Excelと同じ表示）。
  • 店舗合計が 0 でも部門ごとに数字がある回は「実施した回」です（部門のプラスとマイナスで合計が0）。部門別の表で中身を見られます。
  • 部門の数字もすべて 0 の回だけを「実施なし」として、前回比・過去平均の計算から外しています。
  • 新しいレポートが出たら、管理者がデータを更新します。前のレポートも「表示するレポート」から選べます。
  • 年換算ロス＝実施した回のロス合計 ÷ その期間の日数 × 365。売価還元をしなかった回をまたぐ日数も足しています。
  • 傾向＝直近2回の年換算 − それより前の回の年換算。プラスは悪化。
  • 急増＝今回が自分の店のいつもの平均より 2σ（標準偏差の2倍）以上多く、かつ ¥20,000 以上。
  • 慢性ロス／慢性益＝4回以上実施のうち 75%以上でロス（益）、かつ年換算 ¥20,000 以上。
  • 1日あたり＝今回ロス ÷ 前回棚卸からの日数。間隔がちがう店舗どうしを比べるときに使います。
